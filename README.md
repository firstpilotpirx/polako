# Polako — сербские слова и фразы для тех, кто говорит по-русски

**Polako** («потихоньку») — тренажёр сербских слов и фраз. Он учит не «топ-2000 слов вообще», а минимум,
который реально нужен в жизни в Сербии: соседи, магазин и булочная, МУП (ВНЖ, ПМЖ, справки), нотариус,
юрист и бухгалтер, врач, детская площадка, разговор с коллегой. Каждый день немного, но надёжно.

**Открыть тренажёр: https://firstpilotpirx.github.io/polako/**

- 🇷🇸 → 🇷🇺 и 🇷🇺 → 🇷🇸: сербское слово — выбрать перевод; русское — выбрать, вспомнить или написать по-сербски.
- Интервальные повторения **FSRS** (как в современном Anki): слово возвращается ровно тогда, когда начинает забываться.
- Озвучка: сербское слово и русский перевод голосами вашего телефона или компьютера.
- Слова отобраны по принципу **80/20**: первые ~110 слов — это больше половины всей разговорной речи,
  дальше — ключевые слова каждой ситуации.
- **Ваши слова и прогресс — только ваши**: в вашем браузере (сразу, без настройки) или в вашем закрытом
  репозитории на GitHub — тогда они общие для всех ваших устройств. Сам сайт одинаковый для всех и ничего личного не хранит.
- С **Claude** можно собрать словарь лично под себя: из своих ситуаций, писем и сообщений (см. ниже).

## Где хранится прогресс

Есть два варианта, переключаются в любой момент: **«Тренажёр» → «Настройки» → «Где хранить прогресс»**.

| | В этом браузере | GitHub |
|---|---|---|
| Настройка | никакой | 5 минут один раз |
| Устройства | одно | все ваши: телефон, ноутбук, планшет |
| Где лежит | в браузере (IndexedDB) | в вашем закрытом репозитории `polako-data` |
| История занятий | нет | каждое сохранение — коммит |
| Если очистить данные браузера | прогресс пропадёт | всё останется в GitHub |

Начните в браузере. Когда захочется заниматься и с телефона, и с компьютера, подключите GitHub:
весь прогресс из браузера перенесётся в репозиторий автоматически.

## 1. Начать за минуту — в браузере

1. Откройте **https://firstpilotpirx.github.io/polako/**.
2. В блоке **«Начать сразу»** нажмите **«Белград: первые разговоры»**.
3. Откройте вкладку **«Словарь»**, поставьте галочки у слов, которые уже знаете, и нажмите
   **«Отметить как изученные»**.
4. Вкладка **«Тренажёр»** → **«Учить по важности»**.

Всё. Прогресс сохраняется в этом браузере после каждого ответа (вверху написано «сохранено в этом браузере»).
Браузер просят не удалять эти данные, но если вы сами очистите данные сайта — прогресс пропадёт.
Чтобы этого не бояться и заниматься на нескольких устройствах — шаг 2.

## 2. Синхронизация между устройствами через GitHub

Нужен бесплатный аккаунт на [github.com](https://github.com). Делается один раз, минут пять.
Те же шаги есть прямо в приложении: «Тренажёр» → «Настройки» → «Подключить GitHub» → «Как создать репозиторий и ключ».

### Шаг 1. Создайте закрытый репозиторий для данных

1. Откройте **https://github.com/new**.
2. **Repository name:** `polako-data` (можно любое).
3. Выберите **Private** — его будете видеть только вы.
4. Больше ничего не отмечайте, нажмите **Create repository**.

### Шаг 2. Создайте ключ доступа только к этому репозиторию

1. Откройте **https://github.com/settings/personal-access-tokens/new**
   (или: аватар → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → **Generate new token**).
2. **Token name:** `polako`.
3. **Expiration:** сколько удобно, например 1 год (потом ключ можно выпустить заново).
4. **Repository access:** **Only select repositories** → выберите `polako-data`.
5. **Permissions** → **Repository permissions** → **Contents** → **Read and write**.
   (Строчка **Metadata: Read-only** включится сама — так и надо.) Больше ничего не трогайте.
6. **Generate token** → скопируйте ключ (начинается с `github_pat_…`). GitHub покажет его только один раз —
   сохраните в менеджере паролей, он понадобится на каждом новом устройстве.

### Шаг 3. Подключите репозиторий в приложении

1. Откройте **https://firstpilotpirx.github.io/polako/** → **«Тренажёр»** → **«Настройки»** → **«Где хранить прогресс»** →
   **«Подключить GitHub»** (при самом первом входе форма есть сразу на стартовом экране).
2. **Репозиторий с данными:** `ваш-логин/polako-data`.
3. **Ключ доступа:** вставьте ключ из шага 2 → **«Подключить»**.

Что произойдёт:

- **Репозиторий пустой** — туда переносятся ваш набор слов и весь прогресс из браузера.
- **В репозитории уже есть данные** (вы подключали его с другого устройства) — прогресс из браузера и из
  репозитория объединяется, ничего не теряется.

На другом устройстве повторите только шаг 3 — подтянутся те же слова и тот же прогресс.

Вернуться к хранению в браузере: «Настройки» → «Где хранить прогресс» → **«В этом браузере»**. Текущий прогресс
скопируется в браузер, ключ на этом устройстве забудется, в репозитории всё останется.

### Как работает синхронизация

- Сайт сам делает коммиты в ваш `polako-data`: после паузы в ответах, раз в пару минут во время занятия,
  в конце раунда и когда вы уходите со страницы. Вверху написано «сохранено в GitHub».
- Когда вы возвращаетесь на страницу, сайт подтягивает то, что вы сделали на других устройствах.
- Перед записью сайт читает свежую версию и объединяет: если вы занимались на двух устройствах, ответы
  складываются, а не затирают друг друга.
- Нет интернета — занимайтесь дальше: всё сохраняется в браузере и уйдёт в GitHub, когда связь появится.
- В репозитории видна вся история: когда и сколько вы занимались. Любое состояние можно откатить.

Что лежит в `polako-data`:

```
polako.json                  метка «это данные Polako»
deck.json                    ваши слова, фразы, ситуации — то, что показывает сайт
prep/trainer-state.json      интервалы FSRS по каждой карточке
prep/vocab-state.json        отметки «уже знаю»
prep/log/2026-10.json        каждый ответ, по файлу на месяц
prep/words.yaml …            исходники колоды (появляются, если словарь собирает Claude, см. раздел 5)
```

## 3. Иконка на телефоне

**iPhone / iPad:** откройте сайт в **Safari** → кнопка **«Поделиться»** → **«На экран „Домой“»** → **Добавить**.
Иконка открывает тренажёр на весь экран.

⚠️ На iPhone приложение с экрана «Домой» хранит данные **отдельно от Safari**. Поэтому:
- при хранении «в браузере» начинайте заниматься сразу в приложении с экрана «Домой» — прогресс из Safari туда не попадёт;
- при GitHub просто подключите репозиторий ещё раз внутри приложения (шаг 3) — подтянется всё.

**Android (Chrome):** меню **⋮** → **«Добавить на главный экран»** (или «Установить приложение»).

## 4. Как заниматься

**Флаги на карточке** показывают языки: вверху — на каком языке слово, над вариантами ответа ↓ — на каком
отвечать.

| Карточка | Что делать |
|---|---|
| 🇷🇸 слово, ↓ 🇷🇺 | выбрать перевод из шести вариантов |
| 🇷🇺 слово, ↓ 🇷🇸 | выбрать, как это по-сербски |
| 🇷🇸 слово → «Показать ответ» | вспомнить перевод, потом честно оценить себя: Снова / Трудно / Хорошо / Легко |
| 🇷🇺 слово → «Показать ответ» | сказать вслух по-сербски и оценить себя |
| предложение с пропуском | выбрать слово в нужном падеже: Idem u {prodavnicu} |
| реплика из диалога | выбрать, что вы ответите |

- Новое слово сначала спрашивается на узнавание, **со следующего дня** — на вспоминание.
- Ответили верно и быстро — слово вернётся через несколько дней, потом через недели. Ошиблись — сегодня ещё раз.
- **Автопереход:** после ответа следующая карточка открывается сама. Кнопка **«⏸ Остановить автопереход»**
  оставляет карточку на экране; паузу можно настроить ползунками прямо под карточкой.
- 🔊 — произнести ещё раз. В «Словаре» 🔊 говорит слово по-сербски, потом перевод по-русски.
- **Цель в день** (по умолчанию 15 новых слов) меняется ползунком на вкладке «Тренажёр».
- **Lat / Ћир** вверху — показать всё латиницей или кириллицей.
- **Статистика:** сколько процентов разговорной речи вы уже понимаете, что держится в памяти, календарь занятий,
  нагрузка на ближайшие дни, прогноз «когда выучу».

## 5. Словарь лично под себя с Claude

Готовый набор — это старт. С [Claude](https://claude.ai) можно собрать словарь под свою жизнь: свои ситуации,
слова из писем хозяйки квартиры, сообщений из садика, документов из МУП. Эта часть — плагин для Claude
в этом же репозитории.

### Установить плагин

**Приложение Claude:** [Customize → Plugins](https://claude.ai/customize/plugins) → **Add** → **Add marketplace** →
вставьте `firstpilotpirx/polako` → найдите **Polako** в **Discover** → **Install**.

**Claude Code:**

```
/plugin marketplace add firstpilotpirx/polako
/plugin install polako-serbian@polako
```

### Подключить к своему `polako-data`

1. Скачайте репозиторий данных к себе:
   ```
   git clone https://github.com/ваш-логин/polako-data.git ~/workspace/polako-data
   ```
2. Откройте Claude в этой папке и скажите `/polako-start` (или просто «давай займёмся сербским»).
3. Claude спросит, что вам нужно, и дальше всё делает сам: добавит ситуации, разберёт присланный текст,
   соберёт следующий раунд слов, проверит переводы — и запушит изменения. На сайте они появятся при следующем
   открытии, прогресс сохранится.

Примеры просьб:

- «Добавь ситуацию: аптека. Минимум слов, чтобы купить лекарство и спросить про дозировку».
- «Вот сообщение от хозяйки квартиры: … — какие слова я тут не знаю? Добавь их».
- «Сделай следующий раунд слов».
- «Как у меня дела?» — статистика и что подтянуть.

### Команды плагина

| Команда | Что делает |
|---|---|
| `/polako-start` | первый запуск (5 вопросов) и меню «что дальше» |
| `/polako-next` | сразу в меню |
| `/polako-text` | «вот текст — что я тут не знаю?» |
| `/polako-update` | перенести данные на новую версию без потери прогресса |

## 6. Безопасность и приватность

- Сайт — статическая страница на GitHub Pages: без сервера, без аналитики, без рекламы.
- В режиме «в браузере» данные никуда не отправляются.
- Ключ GitHub хранится **только в вашем браузере** (localStorage) и отправляется **только** на `api.github.com`.
  Он даёт доступ лишь к одному репозиторию `polako-data` и только к файлам в нём.
- Потеряли телефон — удалите ключ на https://github.com/settings/personal-access-tokens, выпустите новый.
- Отключить устройство: «Тренажёр» → «Настройки» → «Где хранить прогресс» → **«В этом браузере»** — ключ на этом устройстве забудется.
- Репозиторий `polako-data` закрытый: ваши слова и прогресс видите только вы.

## 7. Вопросы и проблемы

**«Ключ не подошёл».** Скопируйте ключ целиком, проверьте, что он не истёк (Expiration).

**«Репозиторий не найден или у ключа нет к нему доступа».** Имя пишется как `логин/polako-data`. У ключа должен
быть выбран этот репозиторий и право **Contents: Read and write**.

**Нет звука.** Озвучку делает ваше устройство. На iPhone: Настройки → Универсальный доступ → Устное содержание →
Голоса — скачайте хорватский (сербского голоса у Apple нет, хорватский читает сербскую латиницу хорошо) и русский.
На компьютере в Chrome/Edge голоса обычно уже есть.

**Ссылка на claude.ai открывает пустой чат на iPhone.** Пользуйтесь сайтом https://firstpilotpirx.github.io/polako/ —
он открывается в браузере и с экрана «Домой».

**Хочу начать заново.** «Тренажёр» → настройки → «Сбросить прогресс». Или откатите коммиты в `polako-data`.

Нашли ошибку в переводе или идея — [Issues](https://github.com/firstpilotpirx/polako/issues).

## 8. Для разработчиков

```
.claude-plugin/        plugin.json, marketplace.json (плагин polako-serbian, маркетплейс polako)
skills/                polako-start (хаб и модули), polako-next, polako-text, polako-update
data/                  базовый лексикон, варианты, ложные друзья, каталог ситуаций
data/packs/            готовые наборы: belgrade-basics.yaml (слова по уровням важности tier 1–3)
schemas/               схемы колоды, ситуаций, профиля
templates/portal/      страница тренажёра: template.html, page.css, i18n.json, *.js
templates/site/        загрузчик публичного сайта (подключение репозитория с данными)
templates/pwa/         иконки
tools/                 частотный анализ, лемматизатор, колода, наборы, страница, сайт, сервер, статистика, FSRS
tests/                 test_fsrs.py (JS = Python), test_serbian.py, page_smoke.js (jsdom)
examples/sample/       вымышленный ученик A1 в Белграде — тестовая папка
docs/architecture.md   как всё устроено и почему
```

- **Проверки:** `bash tools/check_all.sh` — правила плагина, FSRS (JS и Python дают одинаковые интервалы),
  лингвистика, весь конвейер на копии примера, страница в jsdom, локальный сервер, сборка сайта.
- **Сайт:** `bash tools/run site.py --out <папка>` собирает `index.html` (движок без данных), `packs/*.json`
  (готовые наборы), иконки и manifest. Публикуется в ветку `gh-pages`:
  ```
  bash tools/publish_site.sh
  ```
- **Хранилища сайта:** браузер — `templates/site/idb.js` (IndexedDB); GitHub — `templates/portal/ghstore.js`:
  REST API, несколько файлов в одном коммите (Git Data API), слияние двух копий прогресса (карточка — по последнему
  повтору, отметки — по времени, ответы — объединение). Выбор хранилища — `templates/site/loader.js` (localStorage `pl.storage`).
- **Принцип:** всё, что может сделать скрипт, делает скрипт. Claude решает, что написать (переводы, примеры,
  диалоги); данные пишут только скрипты (`tools/*.py`).

### Источники данных

Частоты разговорной речи — субтитры OpenSubtitles ([hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords),
CC BY-SA 4.0); формы слов — [UniMorph hbs](https://github.com/unimorph/hbs) (CC BY-SA 3.0); частоты
[wordfreq](https://github.com/rspeer/wordfreq). Корпуса скачиваются при установке плагина; в репозиторий попадают
только производные частоты.
