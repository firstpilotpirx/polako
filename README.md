# Polako — сербские слова и фразы, собранные лично под вас

**Polako** (`polako-serbian`) — плагин для Claude, который собирает персональный словарь сербского
и тренирует его. Не «топ-2000 слов», а то, что нужно именно вам: частотность живой разговорной речи,
ваши ситуации (пекарня, МУП, аренда, аптека, банк) и тексты, которые вам реально приходят — Viber от
хозяйки, письмо из МУП, объявление в подъезде. *Polako* — «потихоньку»: каждый день немного, но надёжно.

## Возможности

- **Мастер за пять экранов кнопок.** `/polako-start`: язык перевода, зачем сербский, уровень, ситуации,
  цель в день. Дальше всё собирается само.
- **Частотный анализ разговорного сербского.** 50 000 словоформ из субтитров (OpenSubtitles)
  лемматизируются: курированный базовый лексикон (~480 самых частых лемм со всеми формами: biti, imati,
  moći, ići, местоимения, предлоги), словарь форм UniMorph (~20 000 лемм с ударениями), восстановление
  диакритики, отсечение окончаний. Хорватизмы и иекавица (kruh, tisuća, mlijeko) отсеиваются — только
  белградская экавица. Топ-1000 лемм покрывает ~85% всего, что говорят.
- **Ваши тексты и ситуации весят больше всего.** Слово из письма хозяйки (kirija) встанет выше частого
  слова, которое вам никто не писал. Формула ранга прозрачна (`score_words.py --explain kirija`).
- **Раунды «что я уже знаю».** Быстрая проверка по частотным полосам (10 слов без перевода — знаете 9 из
  10, вся полоса известна), потом пачки по 50. Раунды идут глубже, пока вы знаете больше половины.
- **Карточки с формами, ударением, ложными друзьями.** kuća · род. kuće · вин. kuću · мест. kući;
  kȕća; «ложный друг: не куча». Видовые пары kupiti / kupovati связываются сами.
- **Тренажёр на FSRS** (как в современном Anki): у каждой стороны карточки свой интервал. Сначала
  узнавание — выбрать перевод, **на слух**, выбрать сербское; со следующего дня — вспоминание. Фразы
  «слышу / говорю», **падежи в предложении** (Idem u {prodavnicu}), **вид глагола**, **ответы в диалогах**
  («Za ovde ili za poneti?» → ваш ответ). Четыре оценки с видимым следующим интервалом, автооценка
  выбора по скорости, «пиявки» уходят на разбор с Claude.
- **Озвучка** встроенными голосами браузера: сербский, а если его нет — хорватский или боснийский
  (страница честно пишет, какой). Режимы «Только на слух» и «Только вспоминать».
- **Статистика:** главная цифра — сколько процентов разговорной речи и ваших текстов вы понимаете;
  покрытие со временем, готовность к ситуациям, память по неделям против цели, «сколько помню через N
  дней», календарь занятий, минуты в день, слабые типы карточек, нагрузка на 30 дней, падежи, трудные
  слова, прогноз по группам. У каждого графика есть табличный вид.
- **Мои тексты:** любой текст показывается с подсветкой — знаю / учу / в колоде / новое; новые слова
  добавляются в колоду с примером из этого же текста. Вставить текст можно прямо на странице.
- **Латиница и кириллица:** хранится латиница, переключатель Lat / Ћир показывает всё кириллицей.
- **Личные интервалы:** после ~300 повторов `fsrs_fit.py` подбирает параметры памяти под вас.

## Установка

### Приложение Claude (чат / Cowork)

1. **[Customize → Plugins](https://claude.ai/customize/plugins)** → **Add** → **Add marketplace**.
2. Вставьте `firstpilotpirx/polako-serbian` и подтвердите.
3. Найдите **Polako** в **Discover** и установите. В новом чате: `/polako-start`.

Без доступа к GitHub: скачайте `polako-serbian.zip` из релиза и **Customize → Plugins → Add → Upload plugin**.

### Claude Code

```
/plugin marketplace add firstpilotpirx/polako-serbian
/plugin install polako-serbian@polako
```

Или из локальной папки: «установи плагин из ~/workspace/polako-serbian» — Claude запустит `install.sh`.

### Команды

| Команда | Что делает |
|---|---|
| `/polako-start` | мастер при первом запуске, потом меню «что дальше» |
| `/polako-next` | сразу в меню |
| `/polako-text` | «вот текст — что я тут не знаю?» |
| `/polako-update` | перенести папку на новую версию без потери прогресса |

## Что запускается и где хранится

- **Скрипты** в `tools/` через `bash tools/run <script>`; окружение Python создаётся один раз в
  `~/.local/share/polako/venv` с тремя закреплёнными пакетами: `pyyaml`, `jsonschema`, `wordfreq`.
- **Корпуса** скачиваются один раз (~33 МБ с GitHub) в `~/.local/share/polako/data`:
  UniMorph hbs (CC BY-SA 3.0), частотные списки OpenSubtitles sr/hr (hermitdave/FrequencyWords,
  CC BY-SA 4.0). По желанию — пары предложений Tatoeba (CC BY 2.0 FR). В плагин и в вашу папку попадают
  только производные частоты.
- **Ваши данные** — локально в `~/polako`: `prep/` (профиль, колода, ситуации, прогресс, журнал
  повторов), `my/` (ваши тексты), `dist/` (страница). В режиме чата страница публикуется как приватный
  артефакт, прогресс — в его собственном хранилище.
- **Локальный сервер** `tools/serve.py` (только 127.0.0.1) сохраняет прогресс страницы в папку и
  не даёт старой вкладке затереть новый прогресс.
- **Бэкапы** перед каждым обновлением в `prep/backups`, откат одной командой. Без телеметрии.

## Разработка

- `bash tools/check_all.sh` после любого изменения: правила плагина, тесты FSRS и лингвистики, полный
  конвейер на копии примера (колода должна совпасть с `examples/sample` байт-в-байт по id), страница в
  jsdom (если установлен), локальный сервер.
- Принцип: **всё, что может сделать скрипт, делает скрипт.** Скилы решают, что написать (переводы,
  примеры, диалоги); данные пишут только скрипты.
